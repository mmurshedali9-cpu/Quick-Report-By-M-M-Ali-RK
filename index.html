☁ One-time sync setup — the same URL on laptop and mobile
  1. Open script.google.com → New project → delete everything → paste the code (button below) → Save.
  2. Deploy → New deployment → Web app → Execute as Me, Who has access Anyone → Deploy → Authorize.
  3. Already using the old script? Deploy → Manage deployments → Edit → New version (paste the new code first).
  4. Paste the Web app URL (ends with /exec) below and press Connect & Sync — on this device and on your other device.
Both apps (Defect Report + Daily Patrol Report) save to the same Drive folder. Changes made on one device appear on the other within about 10–20 seconds. If both devices edit the same report at the same moment, the one saved last wins. Keep the URL private.
